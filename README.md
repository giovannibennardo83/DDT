# DDT Manager

Mini applicazione web per creare, archiviare e stampare Documenti di Trasporto (DDT).

## File principali

- `index.html`: form di inserimento e lista archivio.
- `app.js`: logica UI (salvataggio, stampa, cancellazione).
- `db.js`: helper storage su `localStorage`.
- `print.html`: layout di stampa del DDT selezionato.
- `styles.css`: stili della UI.
- `manifest.json` e `sw.js`: base PWA/offline.

## Uso

Apri `index.html` in un browser moderno.
